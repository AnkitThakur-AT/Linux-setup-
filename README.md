
# Cybersecurity Lab Setup

A practical project documenting my cybersecurity lab
environment using VirtualBox and Kali Linux.

## Project Overview

The objective of this project is to build a controlled
virtual lab for learning networking and cybersecurity
fundamentals.

## Objectives

- Configure a virtual machine environment.
- Set up VirtualBox network connectivity.
- Understand NAT Network configuration.
- Verify network settings and connectivity.
- Document practical work with screenshots.

## Tools Used

- Oracle VirtualBox
- Kali Linux
- 7-Zip
- Windows 10
